# gethighandfly — Журнал решений (ADR)

## ADR-001 — Astro 5 + Tailwind как основной стек
- **Дата:** 2026-09-04
- **Статус:** Принято
- **Контекст:** Нужен сайт соревнований с быстрой загрузкой, SEO-совместимостью
  и возможностью AI-генерации контента через Website Factory. В портфеле уже
  работают `kitemuine.com` и `vietnam-kitesurfing` на Astro 5 — команда
  (агент) знает стек, есть готовые паттерны (Dockerfile, nginx.conf, i18n).
- **Решение:** Astro 5 static + TypeScript strict + Tailwind 3 + `@astrojs/sitemap`.
  Деплой: `astro build` → Docker `nginx:alpine`. Образец: `../kitemuine/`.
- **Альтернативы:**
  - *WordPress* — отвергнут: избыточен для статичного сайта соревнований,
    требует PHP-хостинг, медленнее, сложнее поддерживать агентом.
  - *Next.js* — отвергнут: сложнее конфигурировать для чисто статичного
    вывода; нет выигрыша перед Astro при отсутствии React-компонентов.
  - *Hugo* — отвергнут: нет паттернов в портфеле, сложнее интеграция
    с Website Factory (Python-скрипты).
- **Последствия:** При добавлении регистрации с бэкендом нужно переключить
  `output` на `'server'` или `'hybrid'` и добавить адаптер — это ADR-002.
