# Get High And Fly — Журнал решений (ADR)

## ADR-001 — Astro (static) как основной фреймворк
- **Дата:** 2026-09-04
- **Статус:** Принято
- **Контекст:** Нужен сайт соревнований, который открывается быстро с мобильного на пляже
  (часто плохой сигнал), SEO-совместим, легко обновляется на новый сезон без правок кода.
  В портфеле уже есть Astro-проекты (kitemuine, vietnam-kitesurfing) — знакомый стек.
- **Решение:** Astro `output: 'static'`, TypeScript strict. Чистая статика в `dist/`,
  API-сервис отдельно. Lighthouse ≥ 95 — hard constraint.
- **Альтернативы:**
  - *Next.js* — отвергнут: тяжелее для чисто статичного вывода, React-рантайм в бандле.
  - *Hugo* — отвергнут: нет Content Collections, хуже интеграция с TypeScript-экосистемой.
  - *WordPress* — отвергнут: избыточен, медленнее, требует PHP-хостинг.
- **Последствия:** Интерактивность только через Astro Islands (минимально).
  Серверная логика (форма) — отдельный сервис.

## ADR-002 — CSS-переменные + Astro scoped styles (без Tailwind)
- **Дата:** 2026-09-04
- **Статус:** Принято
- **Контекст:** Проект требует дерзкий кастомный дизайн с сигнатурными элементами
  (зернистые текстуры, «ветровые» линии, крупная типографика). Tailwind даёт утилитарный
  look, который сложно превратить в уникальный стиль экстрим-события.
- **Решение:** CSS-переменные в `src/styles/tokens.css` + Astro scoped styles в компонентах.
  Никаких CSS-фреймворков, никаких UI-китов.
- **Альтернативы:**
  - *Tailwind* — отвергнут: утилитарный стиль плохо подходит для кастомного дизайна,
    лишний вес в HTML, сложнее делать сигнатурные анимации.
  - *CSS Modules* — не нужны; Astro scoped styles решают ту же задачу нативно.
- **Последствия:** Разработчик пишет больше CSS вручную. Зато полный контроль
  над дизайном и нулевой overhead.

## ADR-003 — Fastify + SQLite как бэкенд регистрации
- **Дата:** 2026-09-04
- **Статус:** Принято
- **Контекст:** Нужна форма регистрации с хранением заявок, счётчиком мест, листом
  ожидания и Telegram-уведомлениями. Astro static не имеет серверной части.
  Нагрузка небольшая (соревнования раз в год, ~200 участников).
- **Решение:** Отдельный сервис `/server/`: Node + Fastify + SQLite (better-sqlite3).
  Проксируется через Caddy на `/api/*`. systemd-юнит.
- **Альтернативы:**
  - *Внешний сервис* (Tally, Google Forms) — отвергнут: нет контроля над счётчиком мест,
    листом ожидания, Telegram-уведомлениями; ограниченный брендинг формы.
  - *Astro SSR* (`output: 'server'`) — отвергнут: загрязняет чистую статику,
    усложняет деплой; при SSR нельзя использовать rsync.
  - *PostgreSQL вместо SQLite* — отвергнут: избыточен для ~200 записей в год,
    дополнительный сервис на VPS.
- **Последствия:** Две независимые части: `dist/` (статика) и `server/` (API).
  Бэкап SQLite — отдельная задача (cron). Данные участников хранятся локально на VPS.

## ADR-004 — Docker + nginx + deploy.sh как деплой
- **Дата:** 2026-09-04 (пересмотрен в тот же день)
- **Статус:** Принято (заменил первоначальный план с Caddy+rsync)
- **Контекст:** На VPS уже работают kitemuine (8081) и vietnam-kitesurfing (8080) по схеме
  Docker + nginx + host nginx proxy. Добавление Caddy создало бы второй reverse proxy
  на том же сервере, конфликт портов 80/443. Единообразие инфраструктуры важнее.
- **Решение:** Docker Compose, контейнер `ghaf` (порт **8084**), `nginx:alpine` внутри.
  `dist/` коммитится в git. GitHub Actions: `npm run build` → коммит dist/ с `[skip ci]` → push.
  Сервер: `bash deploy.sh` → `git pull` + `docker compose up -d --build`.
  Host nginx (Ubuntu, `/etc/nginx/sites-available/gethighandfly.com`) проксирует на `127.0.0.1:8084`.
  SSL — certbot (Let's Encrypt).
- **Альтернативы:**
  - *Caddy + rsync* — отвергнут при реализации: конфликт с уже работающим host nginx на VPS;
    SSH-секреты в GitHub Secrets усложняют setup без реальной выгоды.
  - *Vercel/Netlify* — не рассматривались: бэкенд-сервис (Fastify, Фаза 3) требует VPS.
- **Последствия:** dist/ в git (~20 KB HTML). Деплой = один `bash deploy.sh` на сервере.
  При смене VPS: клонировать репо, настроить host nginx, certbot — 15 минут.
  Порт 8084 зафиксирован; 8080–8083 заняты другими проектами.

## ADR-005 — i18n: prefixDefaultLocale: true (en как /en/)
- **Дата:** 2026-09-04
- **Статус:** Принято
- **Контекст:** Astro i18n может отдавать дефолтный язык на `/` (без префикса) или на `/en/`.
  Корень `/` нужен для Caddy-редиректа по Accept-Language.
- **Решение:** `prefixDefaultLocale: true` → все три языка на явных префиксах (`/en/`, `/ru/`, `/vi/`).
  nginx (внутри контейнера) обрабатывает `/`: читает cookie `lang` (ручной выбор) или `Accept-Language` → 302.
- **Альтернативы:**
  - *prefixDefaultLocale: false* (en на /) — отвергнут: `/` занят английским,
    нет места для Caddy-редиректа по локали.
- **Последствия:** Все canonical-ссылки, sitemap, hreflang — с явными `/en/` префиксами.
  `x-default` hreflang → `/en/`.
