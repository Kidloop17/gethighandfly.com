# gethighandfly — Спецификация

## Что строим и зачем

Официальный сайт соревнований по кайтсерфингу **Get High and Fly**.
Цель: единая точка для участников и зрителей — расписание, онлайн-регистрация,
результаты, фото и видео с соревнований.

## Роли и сценарии

**Участник соревнований:**
- Узнаёт даты и локацию следующего этапа
- Регистрируется онлайн, получает подтверждение
- Видит свои результаты после этапа

**Зритель / болельщик:**
- Смотрит расписание, узнаёт как добраться
- Просматривает фото и видео прошедших соревнований

**Организатор (владелец):**
- Публикует расписание и результаты
- Управляет списком участников

## Функциональные требования

### Обязательные (MVP)
- Главная страница: анонс ближайшего этапа, дата, локация, CTA
- Страница регистрации: форма с данными участника, подтверждение на email
- Расписание этапов: список с датами, локациями, статусами
- Результаты: таблица по этапам / категориям
- Медиа: галерея фото, раздел видео (embed YouTube/Vimeo)
