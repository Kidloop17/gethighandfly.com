# Get High And Fly — Спецификация

## Манифест

GHAF — ежегодные соревнования по кайтсерфингу, дисциплина big air.
Сайт — шаблон на годы вперёд: новый сезон = один JSON-файл, без правок кода.
Дерзкий, энергичный дизайн. Mobile-first. Lighthouse 95+ по всем метрикам.

## Роли

| Роль | Сценарий |
|------|---------|
| Райдер | Узнаёт даты, условия, категорию → регистрируется |
| Зритель | Расписание, как добраться, где смотреть |
| Партнёр | Тиры спонсоров, контакт для партнёрства |
| Волонтёр | Кто нужен, что получает, кнопка отклика |
| Организатор | Видит заявки, публикует результаты (вне сайта) |

## Языки

Русский, английский, вьетнамский. Все три обязательны с Фазы 0.
`en` — default locale, URL `/en/`. Корень `/` — Caddy-редирект по Accept-Language.
Ручной выбор языка запоминается в cookie — редирект не перебивает его.

## Секции лендинга

### Hero
Фоновое видео (луп, WebM + MP4 + постер), логотип, даты сезона, название спота,
счётчик обратного отсчёта до старта, кнопки «Зарегистрироваться» и «Как это было».
На мобильных — статичный постер-кадр вместо видео.

### Вступление
2–3 абзаца: что за событие, для кого, чем отличается.
Три ключевых числа: год, кол-во участников, рекорд высоты.

### Дисциплины и категории
Карточки категорий: Мужчины Про, Женщины Про, Любители, Юниоры (U18).
Требования к участнику и формат зачёта. Данные из коллекции `categories`.

### Спот
Видео места + текст: почему дует, сезон ветров, статистика по месяцам.
Карта с точками: старт, парковка, зрительская зона, кемп.
Виджет прогноза ветра (Windguru/Windy iframe, lazy-load).

### Партнёры и спонсоры
Логотипы по тирам: генеральный / партнёры / инфопартнёры.
Блок «стать партнёром» с контактом.

### Волонтёры
Кто нужен (судьи, фото/видео, медиа), что получают, кнопка отклика.

### Архив сезонов
Табы-переключатели годов. Галерея выбранного года прямо под табами (без смены страницы).
Вкладка текущего сезона при status=upcoming/registration-open → CTA регистрации.
Вкладка past → фото, видео, победители, таблица результатов.
Переключение табов не дёргает высоту страницы.

### Регистрация
Поля: имя/фамилия, email, телефон, страна, категория, опыт, размер кайта,
чекбокс согласия с правилами и обработкой данных.
Счётчик занятых мест (`GET /api/slots`). Лист ожидания при заполнении категории.
В Фазе 1 — только вёрстка и валидация, отправка не работает.

### Футер
Контакты, соцсети, Telegram-канал, переключатель языка, юрблок.

## Схема сезона (`src/content/seasons/YEAR.json`)

```json
{
  "year": 2026,
  "status": "upcoming | registration-open | live | past",
  "dates": { "start": "YYYY-MM-DD", "end": "YYYY-MM-DD" },
  "spot": "TODO",
  "participantsCount": 0,
  "recordHeight": 0.0,
  "winners": [
    { "category": "pro-men", "name": "TODO", "height": 0.0, "photo": "TODO" }
  ],
  "results": [],
  "gallery": { "photos": [], "videos": [] },
  "aftermovie": "https://..."
}
```

`status` управляет поведением вкладки архива: что показывать и какие кнопки.

## Функциональные требования — бэкенд (Фаза 3)

- `POST /api/register` — валидация (zod), запись в SQLite, ответ
- `GET /api/slots` — счётчик занятых мест по категориям, кэш 60 сек
- Антиспам: honeypot + rate limit по IP + проверка времени заполнения
- Telegram-уведомление организаторам при новой заявке
- Email-подтверждение участнику на трёх языках
- Лист ожидания при переполнении категории
- Лимиты мест по категориям: `TODO: заполнить владельцем`

## Требования доступности и UX

- `prefers-reduced-motion: reduce` отключает всю анимацию
- Видимый focus-ring на всех интерактивных элементах
- Контраст текста ≥ 4.5:1
- Шрифт: полная поддержка вьетнамской диакритики и кириллицы
- Вьетнамский и русский на 20–30% длиннее английского — макет не должен ломаться

## Что мы НЕ делаем

- Онлайн-оплата взносов (MVP)
- Мобильное приложение
- Трансляция в реальном времени
- React/Vue/Svelte без явного согласования
- Серверный рендеринг Astro (SSR) — только static + отдельный API-сервис

## Бэклог после запуска (не в текущих фазах)

- Публичный список участников (показывать после 10+ регистраций)
- Telegram-бот: FAQ, уведомления, регистрация через бот
- Раздел новостей (отдельная коллекция)
- Live-результаты во время соревнований
- Зал славы: чемпионы всех лет одной страницей
- Профили райдеров с историей участия
